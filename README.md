# telegram-dark

A Telegram Desktop style dark look for the Claude desktop app: a black wallpaper
with faint hand-drawn doodles, see-through side panels, slate grey input and
assistant bubbles, and Telegram's bright green for accents and your own messages.
Bubbles carry a curled tail like Telegram's.

Works on Windows and macOS.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install telegram-dark --marketplace Feruzbek-Sapayev/claude-telegram-theme
```

Answer `y` to add the marketplace, then press Enter to pick the user scope.

From a shell:

```
claude plugin install telegram-dark --marketplace Feruzbek-Sapayev/claude-telegram-theme
```

In the Claude desktop app: click **+** next to the prompt box, then **Plugins**,
**Add marketplace** with `Feruzbek-Sapayev/claude-telegram-theme`, then **Add plugin**.

The theme applies to every new chat. In a chat that was already open, run
`/reload-plugins` or reopen it.
